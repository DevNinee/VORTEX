Roadmap de estudos para iniciar o projeto com Python + FastAPI
Ordem recomendada para estudar e implementar no VORTEX:
Etapa 1

Fundamentos de Python

Variáveis, funções, listas/dicts, módulos, venv e pip.

Etapa 2

Estrutura de projeto

Pastas, requirements.txt, .env, separação de rotas/lógica.

Etapa 3

Framework web (FastAPI recomendado)

Rotas (GET/POST), validação com Pydantic, status code.

Etapa 4

Persistência de dados

Comece com SQLite, depois SQLAlchemy e PostgreSQL.

Etapa 5

Autenticação

JWT, login, proteção de rotas.

Etapa 6

Testes

pytest + testes de rota.

Etapa 7

Deploy

Docker básico + deploy (Render/Railway/VPS).
